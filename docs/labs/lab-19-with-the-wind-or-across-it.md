# Lab 19. With the wind or across it

Level 2: Less help

Trainer address: https://alibulentkoc.github.io/multirotor-flight-trainer/

- You cannot break anything. This is a simulator. Crashing costs nothing.
- If anything goes wrong, press **R**. The drone returns to the start, good as new.
- There is no time limit. Only your best try counts.

**The keys**

```
W / S   up / down            Arrow Up / Down     forward / back
A / D   turn left / right    Arrow Left / Right  slide left / right
T  take off    L  land    R  start over    C  change view    P  flight plan
1  Position hold    2  Altitude hold    3  Stabilized
Space  motors on / off       Shift  full stick
```

Orange arms mark the front of the drone. Pressing **1** at any time gives you all the help back.

---

**Goal:** see how wind changes a survey, depending on which way the flight lines run.

**Start**
1. Open the trainer address.
2. Click once on the picture of the field.
3. In "Conditions and view", set **Wind at 10 m** to 4 m/s. Leave "Wind from" at 270 deg (from the west).
4. Press **P**. Check that **Survey area** is selected. Click **Whole field**.

**Do**
1. Set "Flight line direction" to 90. The lines now run east and west, along the wind.
2. Click **Fly this plan**. Leave the time at 1x so you can read the numbers.
3. On a leg flying west, into the wind, write down "Ground speed" and "Airspeed".
4. On a leg flying east, with the wind, write down the same two numbers.
5. After it lands, set "Flight line direction" to 0. The lines now run north and south, across the wind.
6. Click **Fly this plan** again. Watch the round instrument. The drone leans sideways on every leg.
7. Write down "Ground speed" on one leg.

| | Ground speed | Airspeed |
|---|---|---|
| Along the wind, flying into it | | |
| Along the wind, flying with it | | |
| Across the wind | | |

**You are done when** your table is full.

**To save time:** after you have your numbers for a run, switch to **8x time**.

**Think about it:** on which leg did the drone work hardest? What does that do to the battery?
